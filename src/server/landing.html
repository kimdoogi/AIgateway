바꿔치기가 아니라 정직하게.

Anthropic · OpenAI · Google · xAI를 단일 IR(중간 표현)로 호출하는 게이트웨이입니다. 모델을 바꿔도 요청은 그대로 — 그리고 게이트웨이가 무엇을 바꿨는지는 전부 보고됩니다.

가입하고 키 발급 Native IR 가이드

왜 이 게이트웨이인가

조용한 변조 금지

파라미터 드롭·클램프·강등이 생기면 반드시 warning으로 보고합니다. 요청이 소리 없이 바뀌어 디버깅 미궁에 빠지는 일이 없습니다.

폴백 체인

fallbackModels 한 줄로 프로바이더 간 자동 전환. 콘텐츠 방출 전 실패만 전환하고, 청구서는 과금된 전 시도 합산 — 원장과 항상 일치합니다.

기존 SDK 그대로

OpenAI·Anthropic SDK의 base URL만 바꾸면 됩니다 (compat 인바운드). reasoning 서명·표면 스티키까지 gateway 확장 필드로 무손실 왕복.

정산 원장

시도별 원장 행 + 키별 예산(soft/hard)·빈도 한도. 지출은 /v0/usage로 셀프 조회 — 왜 막혔는지 보이는 402/429.

결정론

같은 IR은 항상 같은 바이트의 wire 요청이 됩니다. 4사 실 API 녹화 골든셋 (요청·응답·스트림 재생·크로스 왕복)이 어댑터의 완성 정의입니다.

스트림 재개·취소

SSE 단선 시 Last-Event-ID로 이어받고, 취소는 즉시 업스트림 중단(과금 중단). 터미널 이벤트는 어떤 경로에서도 보장됩니다.

3분 시작

  1. 포털에서 가입 — 이메일·비밀번호면 끝. 테넌트가 만들어집니다.
  2. API 키 발급 — 포털에서 클릭 한 번. 기본 예산·빈도 한도가 부착된 gwk_... 키를 받습니다.
  3. 호출 — 모델 이름만 바꾸면 4사 어디로든 갑니다.
curl https://<gateway>/v0/responses \
  -H "authorization: Bearer gwk_..." \
  -H "content-type: application/json" \
  -d '{
    "version": "0",
    "model": "claude-haiku-4-5",
    "fallbackModels": ["gpt-5.6-luna"],
    "maxOutputTokens": 256,
    "messages": [
      { "role": "user", "blocks": [ { "type": "text", "text": "안녕!" } ] }
    ]
  }'
기존 코드가 OpenAI/Anthropic SDK라면 base URL만 https://<gateway>/compat/openai/v1 또는 /compat/anthropic으로 바꿔도 됩니다 — Native IR 전환은 준비될 때 하세요.
