시작하기

발급 → 호출 → 정산까지 한 게이트웨이. 인바운드 형식이 무엇이든 실행 경로는 동일합니다.

STEP 1 · 관리자

가상 키 발급

가상 키 관리에서 테넌트별 gwk_ 키를 발급합니다. 키마다 분당 요청 한도와 기간 예산(soft/hard)을 겁니다.

STEP 2 · 사용자

어떤 형식으로든 호출

native IR · OpenAI 호환 · Anthropic 호환 — 셋 중 편한 형식으로 호출하면 4사(anthropic/openai/google/xai) 어디로든 라우팅됩니다.

STEP 3 · 운영

사용량 · 정산

모든 시도가 원장에 테넌트·키·비용으로 귀속됩니다. 사용량 리포트에서 집계·CSV, 키 사용자는 내 키 · 사용량에서 자기 지출을 봅니다.

플레이그라운드

발급받은 키로 바로 호출해 봅니다. 스트림이면 SSE 이벤트가 실시간으로 흐릅니다.
